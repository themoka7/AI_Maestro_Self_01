# 1회차 · 내 업무용 Skill 개선 — 수강신청 부하테스트 리포트 자동화

> **과제** : AI Maestro 1회차 · 내 업무용 Skill 개선 (마감 2026-08-30)
> **업무** : 수강신청 시스템 운영 담당 — 학기별 수강신청 오픈 전 부하테스트 결과 리뷰
> **산출물** : `generate_report.py` — WhaTap 성능추이 CSV → 부하테스트 리뷰용 HTML 리포트 자동 생성

---

## 1. 배경 — 기존 업무 방식과 문제점

수강신청은 오픈 시각에 접속이 한꺼번에 몰리는 업무라, 매 학기 오픈 전에 LoadRunner로 부하테스트를 하고
WhaTap APM 지표로 결과를 리뷰합니다. 기존에는 이 리뷰 자료를 **사람이 손으로** 만들었습니다.

| 단계 | 기존 방식 (수작업) |
|------|------------------|
| 데이터 확보 | WhaTap 화면을 시간대별로 캡처 |
| 회차 구분 | 차트를 눈으로 보며 "몇 시~몇 시가 1차" 식으로 구간 판단 |
| 지표 정리 | 회차별 최대 TPS·응답시간·Active Tx를 엑셀에 옮겨 적음 |
| 보고서 | 캡처 + 표 + 코멘트를 문서로 편집 |

**문제점**
- 매 회차 같은 작업을 반복 → 시간 소요
- 회차 경계·피크 값을 사람이 판단 → 작성자마다 기준이 달라짐
- 캡처 이미지라 수치 재확인·비교가 어려움

## 2. 개선 내용 — Skill로 만든 것

**"날짜·시간대만 지정하면 같은 형식의 리포트가 나오는"** 재사용 도구로 만들었습니다.

| 기능 | 내용 |
|------|------|
| CSV 파싱 | WhaTap 성능추이 CSV(5분 버킷)를 그대로 입력 |
| 부하 세션(회차) 자동 탐지 | `TPS ≥ 임계`인 버킷을 활성으로 보고, 간격 `≤ N분`이면 같은 회차로 병합 |
| KPI 자동 계산 | 회차별/전체 최대 TPS, 최대 평균 응답시간, 최대 동시 Active Tx, 피크 동시접속, 총 처리요청 추정 |
| 추이 차트 | TPS·응답시간·Active Tx 시간대별 SVG 차트 (외부 라이브러리 없음) |
| 정성 분석 첨부 | 원인 분석·작업 기록 마크다운을 `--notes`로 넘기면 리포트 하단에 섹션으로 첨부 |
| 산출물 | 라이트/다크 테마, 반응형, **의존성 없는 단일 HTML** — 메일·메신저로 바로 공유 가능 |

**Before → After**

| 항목 | Before | After |
|------|--------|-------|
| 리포트 작성 | 수작업 편집 | 명령 1줄 실행 |
| 회차 구분 기준 | 사람 판단 | 임계·간격 파라미터로 일관 적용 |
| 결과 형태 | 캡처 이미지 + 엑셀 | 수치표 + 차트가 들어간 단일 HTML |
| 재사용 | 매번 새로 작성 | 다음 학기에도 날짜만 바꿔 실행 |

## 4. 사용법

### 요구사항

- Python 3.8+ (표준 라이브러리만 사용, 추가 설치 불필요)

### 빠른 시작

```bash
python generate_report.py --csv sample_perf.csv --out sample_report.html
```

### 옵션

```bash
python generate_report.py --csv <성능추이.csv> [옵션]
```

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `--csv` | WhaTap 성능추이 CSV 경로 (필수) | — |
| `--title` | 리포트 제목 | 부하테스트 결과 리포트 |
| `--out` | 출력 HTML 경로 | `<csv이름>_report.html` |
| `--start` / `--end` | 분석 구간 필터 (`"2026-07-27 10:00"`) | 전체 |
| `--notes` | 정성 분석 마크다운(.md) 첨부 | 없음 |
| `--tps-threshold` | 세션 탐지 TPS 임계 | 50 |
| `--max-gap-min` | 세션 병합 최대 간격(분) | 30 |

예시:

```bash
python generate_report.py --csv perf.csv \
  --title "수강신청 부하테스트" \
  --start "2026-07-27 10:00" --end "2026-07-27 17:00" \
  --notes 작업기록.md \
  --out report.html
```

### 데이터 수집 (WhaTap)

1. WhaTap 로그인 → 대상 프로젝트
2. **애플리케이션 › 분석 › 성능 추이** 이동
3. 상단에서 **날짜·시간대 지정** 후 **파란 조회(돋보기) 버튼**을 눌러 차트가 해당 구간으로 갱신되는지 확인
   - (성능 추이 화면은 날짜 컨트롤이 실제 적용돼야 차트가 바뀝니다)
4. **CSV** 버튼 → 다운로드

CSV 헤더 형식:

```
"Timestamp","Realtime User (count)","TPS","Response Time (ms)","CPU (%)","Heap (byte)","Active Tx (count)"
```

### 세션 자동 탐지 방식

- `TPS >= tps-threshold`(기본 50)인 5분 버킷을 **활성**으로 판단
- 활성 버킷 사이 간격이 `max-gap-min`(기본 30분) 이하이면 **같은 세션**으로 병합
- 세션별로 최대 TPS / 최대 평균 응답시간 / 최대 동시 Active Tx / 피크 동시접속을 계산

부하 패턴에 맞춰 임계·간격을 조정하세요.

### 정성 분석 첨부 (`--notes`)

작업 기록·원인 분석을 마크다운으로 작성해 `--notes`로 넘기면 리포트 하단에 **정성 분석 섹션**으로 붙습니다.
(제목·목록·표·코드블록·인용구 지원)
